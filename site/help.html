把你的收藏搬进来。

本项目不内置游戏。把你可使用的 ROM 放入 Compose 挂载的目录，等待约 15 秒，刷新大厅即可。

只有 ROM 文件

roms/
  fbneo/
    你的游戏.zip
  mame2003_plus/
    你的游戏.zip

文件夹名可选：fbneo、mame2003_plus、fbalpha2012_cps1、fbalpha2012_cps2。对应文件夹会自动选择核心，其余文件夹使用 DEFAULT_CORE。

完整的游戏整合目录

解压外层 7z，保留 gamelist.xml、各分类目录、封面和视频的相对位置。街机 ROM 自身的 zip 不解压、不重命名。可以直接挂载含 gamelist.xml 的目录。

键盘与手柄

先将大厅窗口切到最前，点击网页空白处或「点击这里后使用手柄」，再操作手柄。切换应用、标签页或使用远程控制浮层后，可能需要重新点击网页。「已识别设备」仅表示浏览器看到了设备；「正在接收输入」才表示本页读到了按键或摇杆变化。

打开游戏后按 A 启动。默认 Select 投币、Start 开始，方向键或左摇杆移动。长按 Select + Start 1 秒打开游戏菜单，方向选择、A 确认、B 继续；全屏、存读档、返回大厅都在菜单中。手柄设置内可逐人分配控制器、修改动作键，键盘 Esc 打开菜单、F 切换全屏。摇杆插在运行浏览器的设备上。部分浏览器的 USB 手柄 API 需要 HTTPS；局域网 HTTP 可以先用键盘或触屏。

存档与兼容性

收藏、最近游玩和模拟器存档保存在当前浏览器。换设备不会自动同步，清理浏览器数据前请从模拟器菜单导出存档。ROM 必须匹配核心版本；无法启动时可尝试切换核心。修改版需要专用核心时可能无法运行。
