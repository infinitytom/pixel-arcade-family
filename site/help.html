键盘与手柄

先将大厅窗口切到最前，点击网页空白处或「点击这里后使用手柄」，再操作手柄。切换应用、标签页或使用远程控制浮层后，可能需要重新点击网页。「已识别设备」仅表示浏览器看到了设备；「正在接收输入」才表示本页读到了按键或摇杆变化。

打开游戏后按 A 启动。默认 Select 投币、Start 开始，方向键或左摇杆移动。长按 Select + Start 1 秒打开游戏菜单，方向选择、A 确认、B 继续；全屏、存读档、返回大厅都在菜单中。手柄设置内可逐人分配控制器、修改动作键，键盘 Esc 打开菜单、F 切换全屏。摇杆插在运行浏览器的设备上。部分浏览器的 USB 手柄 API 需要 HTTPS；局域网 HTTP 可以先用键盘或触屏。

画面与金手指

游戏菜单中打开「画面 · 滤镜与机台」，可以实时切换原始像素、柔和、轻量 CRT、木纹／奶白街机机台遮罩与屏幕纹理，设置为当前游戏单独保存。「金手指」按当前核心显示可用项目，默认关闭；数据库需由部署者单独安装，FBNeo 提供选项列表，MAME 2003 Plus 使用核心原生菜单。

金手指：进入、设置、退出

游戏中按 Esc、点击「游戏菜单」，或使用你设置的手柄菜单组合键，再选择「金手指」。FBNeo 在中文列表中选中项目后左右切换开关，按 B / Esc 或点击「继续游戏」退出界面。关闭效果请把项目设为「关闭」，也可用「关闭全部金手指」；退出菜单不会自动关闭效果。

MAME 2003 Plus：打开核心菜单 → Cheat（金手指）→ Enable/Disable a Cheat（开启／关闭项目）。上下选择，左右切换 On（开启）／Off（关闭），动作 A 进入、动作 B 返回上级。按 Esc、手柄 Home 或菜单组合键回到游戏菜单，或点击画面上的「退出金手指并继续游戏」。原生菜单当前仍为英文，金手指页和屏幕指引提供中文对照。

全局设置、全屏与继续

大厅「游戏厅设置」可以设定默认滤镜、机台遮罩、金手指策略和图标风格。单款游戏的画面设置优先，也可在游戏中选择「使用全局默认」。开始游戏默认全屏；浏览器限制自动全屏时先填满窗口，右上角始终可打开游戏菜单。有继续点时，启动页可选「继续上次游玩」或「开始新游戏」。继续点约每 30 秒更新，通过菜单返回大厅也会尝试保存；不覆盖手动存档。

缓存维护与手柄恢复

在游戏厅设置中可手动清理下载缓存，或设置每天、每周、每月清理。只清理可重新下载的 ROM、BIOS 和核心缓存，不删除存档、继续点、收藏、最近记录或按键配置；定期清理只在打开大厅时执行。手柄无反应时先点击网页、松开按键，再用 Esc 或右上角游戏菜单进入手柄设置，选择「重新识别并自动分配手柄」。图标识别不准可在全局设置手动选择风格，图标选项不会改变按键绑定。

存档与兼容性

收藏、最近游玩和模拟器存档保存在当前浏览器。换设备不会自动同步，清理浏览器数据前请从模拟器菜单导出存档。ROM 必须匹配核心版本；无法启动时可尝试切换核心。修改版需要专用核心时可能无法运行。
