## 已有用户更新

**不需要重新导入游戏。先备份配置和导出重要存档。**

Git 用户在原项目目录运行：

```sh
git pull --ff-only
mkdir -p cheats
docker compose up -d --build
```

ZIP／飞牛用户：解压新版，将程序文件合并到原项目，保留 `.env`、`roms/`、`cheats/`，然后在原 Compose 项目重新构建并启动。单纯拉取镜像不能更新本地源码构建的安装。

更新后关闭旧游戏页面，回到大厅 `Ctrl+F5` 刷新，不要清除网站存储。金手指数据库需另行安装；滤镜、边框与遮罩无需下载额外资源。完整下载命令、飞牛操作、目录说明、兼容范围与回退步骤见 [更新部署指南](update.md)。
