# 家庭版验证记录

## 2026-10-21 手柄与字体更新

新增标准 Gamepad 大厅导航、首次引导与随时可开的操作指南、焦点提示、屏幕键盘、分类和排序、分页、收藏、视频播放与暂停、核心切换、启动和返回后恢复筛选。帮助、赞助、检测页可手柄浏览和返回；游戏页提供暂停菜单和浏览器快捷存读档。正文、游戏名、分类与详情字体已增大。

`scripts/check_gamepad.cjs` 使用 Edge / Chromium 和模拟 Gamepad 验证方向、摇杆死区、弹窗、收藏、预览、核心、翻页边界、长按按钮不重复触发、屏幕键盘、断线重连、启动返回、引导、辅助页面以及 390 / 750 / 1280 / 1920 宽度无横向溢出。游戏菜单暂停和快捷存读档使用模拟的 EmulatorJS 对象验证适配；尚需实际游戏和实体手柄验收，不能据此宣称所有控制器与核心均兼容。Python 的 9 项服务测试通过。

本地运行浏览器检查：安装 Playwright 后执行 `node scripts/check_gamepad.cjs`；Windows 可设置 `BROWSER_CHANNEL=msedge` 使用现有 Edge。CI 在 Chromium 中运行同一检查。

验证日期：2026-10-20。

## 2026-10-22 虚拟手柄冲突修复（v1.1.1）

用户确认 UU 虚拟手柄在检测页有效，但大厅无响应，游戏内尚未测试。实机浏览器枚举同时得到 Arduino Leonardo（非标准映射，轴约 0.693 / -0.646）和 Xbox 360 标准手柄。旧逻辑会被 Leonardo 的持续轴值抢占，卡在等待归中状态。

修复后默认优先标准手柄，其他设备仅在新输入时才参与同类控制器切换；允许手动指定大厅控制器，并显示当前设备、焦点和归中状态。自动回归加入上述双设备复现和第二只标准手柄保持偏轴的情况，验证导航、确认和手动切换。Select+Start 改为打开暂停菜单，再通过两次确认返回大厅，兼容虚拟手柄缺少 L3/R3 的操控方案。实体游戏操作与模拟器原生设置、文件选择弹窗仍未验收。

本次同时增加「手柄设置」对话框，验证组合键和长按时间修改、死区和导航速度、设置持久保存、重载恢复及一键重置。设置只影响大厅和自定义菜单，不改变模拟器原生玩家分配。

## 2026-10-22 窗口焦点与输入状态（v1.1.2）

用户最终确认：保持大厅窗口在最前并点击网页后，UU 虚拟 Xbox 可以操作大厅。Windows XInput 同时捕获到 A 键和左摇杆变化。独立后台浏览器的设备枚举与「已就绪」状态未能证明真实按键到达该页，不能作为实际操作验收证据。

新版将状态区分为已识别、正在接收、已收到输入和已暂停接收，增加点击激活入口与焦点操作引导。blur、visibilitychange 和 pagehide 同步更新暂停提示，避免动画帧停滞时仍显示旧的就绪状态；重新聚焦等待松开按键。浏览器回归覆盖同步失焦提示、暂停期间忽略操作、重新聚焦不误触发，以及真实输入变化才确认接收。UU 的大厅操作已有用户实测；游戏内、多人及其他实体型号仍待验证。
