# 像素放映厅 v1.2.1：排序导航与自动存档修补

## 修复内容

- 首页「排列」使用网页内按钮，确认／左右切换排序，上移到搜索、下移到游戏列表，返回键可直接离开。避免原生下拉窗口抢占焦点，修复窄屏鼠标按下时输入图标变化造成的控件位移。
- 自动存档按前台、未暂停的累计游玩时间，每满 3 分钟保存。移除启动几秒和打开菜单触发；暂停、后台、失焦及关闭自动保存期间不累计时间。
- 离开页面或返回大厅更新本局最近的自动恢复点，合并重复事件，不连续挤占历史槽。界面区分「定时自动存档」与「离开前自动保存」。手动存档、独立历史名额及缩略图保留。

## 已有安装升级

Git 用户在原项目目录执行：

```sh
git pull --ff-only
mkdir -p cheats
docker compose up -d --build
docker compose ps
```

ZIP／飞牛用户下载 **pixel-arcade-family-v1.2.1.zip**，合并程序文件并在原 Compose 项目重新构建。保留 `.env`、`roms/`、`cheats/` 和自定义游戏目录。继续沿用原来的域名、协议和端口，关闭旧游戏页后在大厅刷新；**不要清除网站存储**。校验文件为 **SHA256SUMS-v1.2.1.txt**。

程序包不含 ROM、BIOS、模拟器二进制或金手指数据库。详细操作见 [更新部署指南](https://github.com/infinitytom/pixel-arcade-family/blob/v1.2.1/docs/update.md) 与 [设置维护](https://github.com/infinitytom/pixel-arcade-family/blob/v1.2.1/docs/settings.md)。

浏览器回归覆盖 390／1600px 排序点击与手柄确认、左右、上下、返回和分区切换；受控时钟验证累计 3 分钟、暂停和后台不计时、菜单不写入、离开前替换最近自动槽、重复事件合并及手动历史保留。真实模拟器检查历史选择、缩略图和存档载入，已有音效、全局设置和账号路径检查继续覆盖。
