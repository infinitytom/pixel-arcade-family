# 画面、手柄、继续游玩与缓存

大厅右上角打开 **游戏厅设置**。游戏中也可在游戏菜单中进入。设置属于当前浏览器；账号入口按当前账号分别保存全局偏好和继续点，不会跨设备同步。

## 全局画面与金手指

设置默认滤镜、轻／中／浓强度、木纹／奶白机台遮罩和屏幕纹理。尚未单独设置的游戏使用这些默认值。游戏中单独调整后优先使用该游戏的设置；选择 **使用全局默认** 可以恢复继承。

全局金手指可设为「允许手动开启」或「关闭功能」。允许使用也不会自动开启任何作弊效果。资源开关在重新进入游戏时生效，具体效果按游戏手动选择；退出菜单不会关闭已经开启的效果。中文说明和 MAME 进入／退出步骤见游戏内金手指页及 [更新指南](update.md)。

## 手柄无反应时

1. 将游戏厅窗口置前并点击网页，松开手柄按钮与摇杆，再重新操作。页面失焦期间不接收游戏输入。
2. 用键盘 Esc 或画面右上角「游戏菜单」进入 **手柄设置**，确认玩家 1／2 的设备分配。
3. 选择 **重新识别并自动分配手柄**。会恢复自动分配，不删除你的自定义动作键。通常以启动游戏或最近操作的手柄作为玩家 1。
4. 多个手柄可分别分配给玩家 1～4，同一设备只能占一个玩家。手动分配会在本局保留；拔插后可以重新选择或恢复自动分配。

本次修复了核心启动时重建分配后未同步，以及稀疏设备编号断开时可能中断轮询的问题。生成的 Gamepad 输入通过真实核心检查，不等于所有实体、虚拟或非标准手柄均已兼容。USB／蓝牙设备仍需浏览器支持，部分浏览器要求可信 HTTPS。

## 输入图标

提示会随最后使用的键盘、鼠标、触屏或手柄切换。已识别的 Xbox、PlayStation 和任天堂手柄显示对应字母或符号；通用标准手柄按物理位置显示，未知非标准设备用按钮编号。各玩家的按键编辑器也按分配设备显示选项名称。

识别不准时，在全局设置中手动选择 **操作图标风格**。这个选项只改变提示，不改变按键绑定。任天堂手柄采用浏览器报告的标准物理位置，例如底部 B 可对应大厅的确认操作。

## 默认全屏和继续

开始新游戏或继续游戏时默认进入全屏视图。浏览器允许时进入浏览器全屏；手柄轮询等未获得浏览器用户激活的场景，先填满当前窗口。可在全局设置关闭，游戏菜单也可退出或选择「进入浏览器全屏」。全屏时右上角仍有游戏菜单按钮。

开启 **自动保存继续点** 后，每个游戏／核心保留最近 3 个自动存档，按前台且未暂停的累计游玩时间，每满 3 分钟保存；通过游戏菜单返回大厅也会尝试保存。已有继续点时，启动页显示 **继续上次游玩** 和 **开始新游戏**，并显示保存时间。选择不显示继续选项不会删除已有继续点。

手动「快捷存档」同时更新继续列表，即使关闭自动保存也有效；列表单独保留最近 3 个手动存档，自动存档不会占用手动名额。大厅详情和启动页均可选择具体时间的进度再继续；游戏中可在菜单的「选择存档进度…」直接恢复。原有快捷存档槽仍可直接读取。升级前的旧快捷存档可先在游戏菜单读取，再重新快捷存档，即可加入列表；此前未保留的历史状态无法补回。关闭网页时最后几秒不一定来得及保存，重要进度仍应手动存档。ROM 或核心版本变化可能导致旧继续点不兼容；载入失败时会提示并允许从新游戏开始。

## 缓存维护

在 **游戏厅设置 → 缓存维护** 查看可清理的引擎缓存占用，选择 **立即清理下载缓存**，或设置每天／每 7 天／每 30 天自动清理。默认不自动清理。

只清理浏览器中可重新取得的 ROM、BIOS 和模拟核心缓存，以及本应用明确拥有的下载缓存。不删除 NAS 原始游戏文件、快捷存档、继续点、收藏、最近游玩或按键配置，不触碰其他类型数据库或其他命名空间的 Cache Storage 缓存。

定期任务仅在大厅打开时检查和执行；浏览器关闭后不会后台运行。浏览器全局 HTTP 缓存不在这个按钮的清理范围内。清理后第一次打开游戏需要重新下载对应文件。
# 本次交互修补

- 对话框内上下方向按阅读顺序逐项移动，并自动滚动到选项；左右方向切换当前选择框，确认键也可切换，返回键退出。
- 游戏厅设置新增即时示例画面，可查看默认滤镜、强度、机台和屏幕纹理的变化。示例用于比较外观，实际游戏使用模拟器的原生滤镜。
- 有继续点时，大厅游戏详情提供「继续上次游玩」和「开始新游戏」；继续点按浏览器、账号、游戏与核心分别保存。没有继续点会显示原因，最近游玩记录本身不等于存档。
- 实际游玩满 3 分钟后定时保存，暂停、后台和失焦不计时；打开菜单不保存，返回大厅或离开页面会更新本局最近的自动恢复点。浏览器强制关闭仍可能来不及完成最后一次保存。
- 中文路径的原文与 URL 编码形式共用继续点，并兼容已有记录。
- DualSense（PS5）显示创建键图形与选项键图形，配中文名称；DualShock 4（PS4）显示分享键和选项键。默认菜单组合键在 PS5 上显示为「创建键 + 选项键」，长按一秒。图标变化不改变按键映射。

## 操作音与存档缩略图

在游戏厅设置的「声音」区域试听、调整音量或关闭声音，默认音量为 20%。音效为程序自制合成，不需要音频资源下载；移动、确认、返回、启动、手动存档成功与存储失败使用不同提示。鼠标悬停不发声，手柄长按移动限频。声音须先通过一次页面点击或键盘按键解锁；游戏内动作不播放大厅音效，自动存档成功保持安静。

新存档记录 256×192 的小幅游戏画面。大厅、启动页和游戏菜单的存档选择器会显示当前所选记录的缩略图与时间；旧记录无图时显示「此存档暂无画面预览」，不影响恢复。截图只留在当前浏览器／账号存档内；截图不可用时仍会保存游戏状态。

启动机台依据已知画面比例提前布局，并记住实际核心报告的比例。第一次运行且无资料的改版游戏可能需要核心报告才能确定比例，可在 gamelist.xml 中明确设置 `<aspectratio>3/4</aspectratio>` 等值。海报入场和选中动画会遵循系统的减少动态效果偏好。

## v1.2.1 排列与自动存档修补

主页「排列」改为网页内切换按钮，不再打开浏览器原生下拉窗口。确认或左右切换目录顺序／名称排序；上移到搜索，下移到游戏列表，返回键也可回游戏列表。鼠标点击时延后输入图标的版式变化，避免按钮在按下和松开之间移动。

自动存档只按前台未暂停的累计游玩时间，每满 3 分钟生成一份定时历史。取消了启动几秒和打开菜单时保存；关闭自动保存期间不累计时间。离开页面或返回大厅会更新本局最近的一份自动恢复点，重复离开事件不会挤占历史槽；界面将其标注为「离开前自动保存」，与「定时自动存档」区分。手动存档仍即时保存并保留独立名额。

## 核心预加载与收藏历史备份

设置中的「预加载游戏库所需核心」只下载当前游戏库所需的默认核心，不下载 ROM。查看详情会准备对应核心，启动时复用；更新后按服务器文件标识重新下载，清理缓存后可再次预加载。

「收藏与游玩历史」显示当前站点入口、账号和记录数量，可导出 JSON 备份、导入同账号备份，或合并恢复本地上一份记录。导入和恢复保留当前记录。它不包含游戏存档或截图，重要存档请在游戏内单独导出。收藏和历史属于当前浏览器的站点数据；切换 IP、域名、协议、端口、账号或浏览器会使用另一份数据。清除浏览器的网站数据会删除这些记录，本应用清理下载缓存不会。

操作音尚未获浏览器允许时，会显示启用按钮。先真实点击页面或按一下键盘，随后即可用手柄播放操作音；试听实际失败时不会显示正在播放。若仍无声，检查标签页静音和系统输出设备。

## 荧光滤镜和立体机台

导入作者资源后，可选择荧光线 2.0 三种预设、荧光点 3.3 两种预设。全局设置的像素城市与游戏中的暂停画面都可运行同款着色器，强度与原画对比无需推进游戏。预设和导入细节见 [荧光滤镜说明](phosphor.md)。机台、屏幕与玻璃采用统一透视，选择关闭机台可使用最大平面画面。继续游戏或读档后会检查音频并保留静音、音量设置；若浏览器仍限制声音，点击恢复声音提示或按一下键盘后继续用手柄游玩。


## 账号同步（v1.4.0）

已接入账号服务的 `/arcade/` 入口提供同步状态与手动重试，可恢复收藏、历史、设置、继续点及缩略图。公开家庭版默认仍在本机保存。首次迁移完成并显示「已同步」后，云端记录才可用于更换设备或恢复浏览器数据；未上传内容仍依赖本机副本。详见 [账号同步说明](account-sync.md)。


## 大厅控制器切换（v1.4.3）

「大厅控制器／菜单控制器」支持左右或确认切换选项，上下离开；大厅按返回可恢复自动并回到游戏列表。选择其他设备后，原手柄继续可用，直到新手柄松开按键与摇杆后按确认接管。接管用的确认不会同时激活其他按钮。目标设备离线时自动回退，重新连接后再次确认接管。该选择只影响大厅和菜单，游戏玩家分配仍单独设置。
