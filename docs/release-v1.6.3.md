# v1.6.3：倒计时保留游戏画面并自动继续

修正继续游戏倒计时背景变黑，以及可见窗口因焦点判断而一直暂停的问题。恢复后先更新视频帧，再从核心取得原生截图保留实际画面；轻半透明 3、2、1 结束后自动继续，无需额外按键。Esc 仍可主动取消，切换到隐藏的页面时暂停倒计时。

MAME 新游戏也自动跳过启动提示，避免停在提示页等待玩家按键。

本地验证包括真实 MAME《恐龙快打》与 FBNeo《拳皇97 最终决战》的新启动、菜单继续、三种滤镜下的暂停画面和重新打开页面读档；检查倒计时期间核心不推进，结束后自动推进，并覆盖可见但焦点报告为 false 的情况。其他游戏和核心仍可能有独立兼容性问题。

## 更新部署

Git 安装执行 `git pull --ff-only` 后 `docker compose up -d --build`；ZIP 安装合并 `pixel-arcade-family-v1.6.3.zip` 后重建。账号入口由同一提交生成。保留 ROM、作者滤镜及完整账号数据目录。

缓存标识 `arcade20`、机台样式 `cabinet16`。关闭旧游戏页后刷新，无需清理网站数据。[更新指南](update.md)。
