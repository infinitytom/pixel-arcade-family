# v1.6.1：修复所有游戏停留在准备中

修复 v1.6.0 引入的引擎初始化缺陷：版本检查在构造阶段读取尚未赋值的 `this.config.dataPath`，可能抛出异常并阻止启动界面出现。改为读取启动前已经设定的 `EJS_pathtodata`，兼容家庭版和 NAS 账号入口。

启动页面仅快速读取已有核心缓存，不再强制等待最长 3 分钟的预下载或网络 HEAD。首次所需核心由模拟器在点击开始后正常下载，并显示进度。账号同步的待上传队列改为后台处理，初始元数据请求限时 5 秒，本地记录与队列保留。

准备阶段列出正在等待的项目；10 秒慢响应提示，30 秒仍未完成时提供重载。下载／初始化 20 秒无进展时显示可重试提示；恢复进度后自动收起。无需清理网站数据。

## 部署

完整更新前端，并重建引擎：`git pull --ff-only` 后 `docker compose up -d --build`。ZIP 安装使用 `pixel-arcade-family-v1.6.1.zip` 合并程序并重建。**只换前端不能修复旧的引擎脚本，必须同时更新 `data/src/emulator.js`。** NAS 账号入口从同一提交生成并核对源码与核心。

保留 ROM、作者滤镜与完整账号数据目录。缓存标识 `arcade18`、机台样式 `cabinet14`。关闭旧游戏页并按 Ctrl+F5 刷新；不需要删除收藏、存档或网站数据。[更新指南](update.md)。

新增真实引擎初始化 CI 检查，直接运行已安装的引擎并验证启动按钮可用；另外覆盖核心缓存直用、冷缓存不预下载、准备超时与迟到响应、下载停滞及进度恢复。原有游戏继续、存档与手柄检查保留。
