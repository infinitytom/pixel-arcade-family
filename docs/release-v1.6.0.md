# v1.6.0：HACK 父资源、暂停倒计时与全屏启动

- 拳皇97 最终决战等分包会自动查找并加载已有父 ROM，优先选择普通版，保留修改版文件；Neo Geo BIOS ZIP 可直接供 FBNeo 读取。原资源和记录标识不变。不支持的专用修改版仍需匹配核心。
- 从启动页恢复、历史进度恢复、快捷读档及菜单继续时，显示游戏画面并暂停，覆上半透明 3、2、1 倒计时后继续。期间屏蔽游戏输入；Esc／手柄返回可暂停，切走窗口会保持暂停并重新准备。
- 跨页面记住最近使用的键鼠、手柄型号及已确认控制器，避免每页重置提示和重复接管。真实输入仍可切换设备，断开设备会回退。
- 收起原生工具栏、通知文字和 RetroArch 菜单快捷键，保留统一游戏菜单。
- 已安装应用请求全屏启动，大厅提供一次点击全屏；Windows 可用 `scripts/create_fullscreen_shortcut.ps1` 创建无地址栏的 Edge 全屏桌面入口。普通标签页无法绕过浏览器要求自动全屏。

## 更新与一致性

家庭版与 NAS 使用同一提交、同一 `engine-lock.json` 和同一前端源码。NAS 账号入口由构建脚本生成必要的登录和路径适配，并逐文件核对部署结果；作者私有滤镜和 ROM 不进入公开发布包。

Git 安装：`git pull --ff-only` 后 `docker compose up -d --build`。ZIP 安装：合并 `pixel-arcade-family-v1.6.0.zip` 后重建原 Compose 项目。保留资源、作者滤镜和完整账号数据目录，本版无账号数据库变更。账号入口重新生成前端，并更新引擎更新检查的本地路径适配。

新增 `rom-parents.json`、`resume-countdown.js`、`fullscreen-launch.js` 必须一并部署；缓存标识 `arcade17`、机台样式 `cabinet13`。关闭旧游戏页并刷新大厅，不要清除网站数据。详见 [更新指南](update.md) 和 [父 ROM 说明](rom-dependencies.md)。校验文件 `SHA256SUMS-v1.6.0.txt`。

《超时空要塞2》部分跨次读档的声音兼容问题仍未彻底解决，沿用已知问题记录，不宣称修复。
