# v1.6.6：在原画布持续显示暂停帧

此前版本仍收到「数字显示，但游戏暂停期间黑屏」的报告。这次处理模拟器暂停时停止呈现的问题：游戏计算保持暂停，原来的 WebGL 画布独立重绘最近的有效帧，上面只显示 3、2、1。没有额外图片、画布、背景或遮罩。

画面在原生绘图时直接保留在 GPU 中，避免读取已经被丢弃的缓冲区。读档时短暂等待有效画面；恢复游戏前停止暂停呈现，并恢复原生图形状态。

验证覆盖 WebGL 1/2、故意清空缓冲区、像素读回全黑、原生帧数保持暂停、无额外图片或画布，以及恢复后的图形状态和游戏推进。真实 MAME《恐龙快打》和 FBNeo《拳皇97 最终决战》检查八种滤镜及跨页面读档；实际用户浏览器仍需复核。

Git 安装执行 `git pull --ff-only` 后 `docker compose up -d --build`；ZIP 安装合并 `pixel-arcade-family-v1.6.6.zip` 后重建。账号入口由同一提交生成。保留 ROM、作者滤镜及完整账号数据目录。

缓存标识 `arcade23`、机台样式 `cabinet19`。关闭旧游戏页后重新进入，无需清理网站数据。[更新指南](update.md)。
