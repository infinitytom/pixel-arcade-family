# v1.5.1：7z 街机资源兼容与画面菜单隐藏

修复浏览器版 FBNeo 禁用原生 7z 支持导致资源存在却无法启动的问题。启动时使用已安装的模拟器解压组件，将 7z 内容临时封装为 ZIP，再交给核心读取。原始资源、游戏路径、收藏、历史和继续点标识不变；无需逐款手动换文件或重建游戏库。普通 ZIP 直接沿用。

隐藏游戏画面右上角的模拟器三条杠菜单。自定义「游戏菜单」、Esc 和手柄菜单快捷键仍可使用。另修正桌面玩竖屏游戏时机台灯箱标题换行、裁切的问题。

启动海报显示解压进度；解压失败会提示重新载入，工作线程和临时资源会清理。7z 转换只解决容器兼容性，游戏仍需与核心、BIOS 和父 ROM 匹配。大资源需要较多浏览器内存，临时 ZIP 随页面关闭释放，不写入账号存档或原 ROM 目录。

## 更新部署

Git 安装执行 `git pull --ff-only`、`docker compose up -d --build`；ZIP 安装合并 `pixel-arcade-family-v1.5.1.zip` 后重新构建原 Compose 项目。账号入口重新生成并部署前端即可，本版不修改账号后端和数据格式。

保留原资源、作者滤镜 JSON、配置与完整账号数据目录。关闭旧游戏页后刷新大厅，无需清除网站数据。缓存标识 `arcade16`，机台样式 `cabinet12`，新增 `library/rom-archive.js` 必须一同部署。详见 [更新部署指南](update.md)。校验文件 `SHA256SUMS-v1.5.1.txt`。

## 验证

真实核心使用原 `mushisam.7z` 通过 4 个 ROM CRC 校验、开机自检、投币和游戏选择；`punisher.7z` 同样通过启动检查。用自制微型 7z 实测原解压组件，生成 ZIP 经 Python 独立验证 CRC、二进制内容、中文文件名和空文件，另检查 ZIP 直通、重复安装保护、损坏包提示与线程回收。覆盖桌面／手机机台、隐藏原生菜单，以及真实核心历史继续和手柄导航回归。
