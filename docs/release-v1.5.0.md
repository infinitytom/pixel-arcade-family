# v1.5.0：大存档同步与轻度做旧机台

账号同步移除单份 16 MB、每账号 512 MB 的应用容量限制，改为 1 MB 校验分块、断点续传和磁盘存储。旧数据库存档与本机待上传队列可直接沿用；NAS 空间不足时保留本机副本并提示重试。每游戏手动、自动各 3 份的保留规则不变。

机台外壳与操作台加入自制 SVG 磨损纹理、轻微泛黄、细划痕和旧金属螺丝；设置预览同步更新，纹理不覆盖游戏画面。保留正面屏幕和立体操作台结构。

继续游戏会等待核心首帧就绪；MAME 继续入口跳过独立于存档的开机声明提示，并在恢复结束后移除海报等待层。**《超时空要塞 2》在 MAME 2003 Plus 下部分跨次读档仍可能无声，本版尚未彻底修复此核心兼容问题。** 保留旧进度，未强制切换核心或重开游戏。同一局内暂停／恢复与跨次读档分别验证，不将音量恢复视为游戏声音已恢复。

## 更新部署

Git 安装执行 `git pull --ff-only`、`docker compose up -d --build`；ZIP 安装合并 `pixel-arcade-family-v1.5.0.zip` 后重新构建原 Compose 项目。保留 `.env`、ROM、cheats、作者滤镜 JSON 和账号数据。

账号入口必须同时更新 `account_sync.py`、重新生成前端并重启账号服务，保留原 `/data` 挂载。旧数据库自动增加新列。新版已完成存档位于 `/data/sync-files/`，待续传分块位于 `/data/sync-uploads/`。**备份与恢复须先停止账号服务，再复制整个持久目录；以后只备份 SQLite 不能恢复完整存档。** 升级前先备份。详见 [账号同步说明](account-sync.md) 与 [更新部署指南](update.md)。

页面缓存标识 `arcade15`，机台样式 `cabinet11`。关闭旧游戏页后刷新大厅，无需清除网站数据。校验文件为 `SHA256SUMS-v1.5.0.txt`。

## 验证

覆盖超过 16 MB 的浏览器间存档字节校验、超过旧 512 MB 总配额的账号、分块中断／刷新续传、重复块、损坏块、账号隔离、旧存档兼容、物理文件保留清理，以及登录服务回归。另检查桌面／手机机台结构、设置预览、控制器导航、真实核心继续、海报入场与音量／静音恢复。

可用 `MACROSS_URL=本地游戏地址 node scripts/probe_macross_resume.cjs` 复现上述声音问题；此诊断需要本地合法 ROM 与核心，不属于无需 ROM 的通过性测试。
