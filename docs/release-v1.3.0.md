# v1.3.0：荧光滤镜、实时预览与立体机台

- 增加本地作者资源导入工具：适配荧光线 2.0 的标准、扩散辉光、玻璃反射，以及荧光点 3.3 的精细 CRT、柔光。效果强度实际作用于着色器参数，全部使用中文选项，保留作者署名。
- 高级滤镜在全局设置中使用同款 GLSL 实时渲染示例；游戏中可处理当前暂停画面、切换强度并对比原画，不推进游戏。
- 屏幕、玻璃、边框和海报过渡共享透视视角；机台增加真实侧面／顶部厚度与向前伸出的控制台。关闭机台时恢复完整平面画面。
- 菜单继续、读档与重新获得焦点后检查游戏自身的音频状态，恢复被挂起的音频和输出音量。保留玩家原来的音量及静音选择；浏览器阻止声音时显示明确启用提示。

## 升级与资源

Git 用户在原项目目录运行 `git pull --ff-only`，再执行 `docker compose up -d --build`。ZIP 用户下载 `pixel-arcade-family-v1.3.0.zip`，合并程序文件后重新构建原 Compose 项目。保留 `.env`、ROM、cheats、自定义路径，以及已导入的 `site/library/private-shaders.json`。

**公开源码和 Release 不分发作者的着色器素材。** 请按 [荧光滤镜导入说明](phosphor.md) 使用自己取得的资源；未安装的高级选项会禁用，原有滤镜正常可用。导入后需要重新构建容器。缓存标识为 `arcade8`，更新后关闭旧游戏页并刷新大厅，无需删除网站数据。

发布包不含 ROM、BIOS 或模拟器二进制。更新步骤见 [更新部署指南](update.md)。校验文件为 `SHA256SUMS-v1.3.0.txt`。

## 验证

本地真实模拟器检查五种作者预设的编译和输出、暂停预览／强度／原画对比、进度不前进、原生音频音量恢复以及 390／1600px 下屏幕与玻璃投影对齐。真实 Web Audio 回归覆盖继续与读档后的延迟挂起、输出增益归零、音量与静音保留。全局预览同时用自制测试着色器验证，CI 无需分发第三方素材。
