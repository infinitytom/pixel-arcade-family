# 常见问题

**第一次构建失败？** 检查飞牛能否拉取 `python:3.12-alpine`，以及访问 `registry.npmjs.org`。查看 Compose 构建日志。官方包的 SHA-512 校验不一致时会主动停止，不建议跳过校验。

**大厅没有游戏？** 确认挂载的是实际的游戏目录，外层 7z 已解压，目录可被 UID/GID 10001 读取，ROM 后缀为 ZIP/7z。新增文件后等待 15 秒再刷新。隐藏目录和符号链接不予扫描。XML 内引用的文件必须在挂载目录中。

**只有文件名、没有封面？** 需要资源包提供 `gamelist.xml` 与对应封面文件。此项目不主动抓取元数据或封面。大小写不同的 XML 引用可匹配，但目录结构不能改变。无效 XML 会在目录加载后显示提示。

**黑屏或无法启动？** 先检查网络请求能否读取 ROM 和核心，再切换核心。部分修改版依赖整合包专用模拟器。不要混用 nightly 核心与本项目锁定的 EmulatorJS 4.2.3。用户可自行评估升级，并同步调整整套模拟器和核心版本。

**手柄没反应？** 摇杆应插在游玩设备上。先用「控制器检测」，再进入模拟器绑定。部分浏览器要求可信 HTTPS 才能使用 Gamepad API，局域网 HTTP 下先测试键盘/触屏。蓝牙设备先在操作系统配对。实际硬件需逐键测试。

**检测页有反应，大厅却不动？** 先将大厅窗口切到最前，点击网页空白处或「点击这里后使用手柄」，再按方向和 A。切换窗口、标签页或远程控制浮层后需要重新激活网页。「已识别设备」只表示枚举成功；请以输入状态和实际操作为准。2026-10-22 用户确认 UU 虚拟 Xbox 在这样激活后可操作大厅，游戏内及多人操作尚未验收。

**存档换设备没了？** 存档、收藏、最近游玩都保存在原浏览器，没有云同步。请在模拟器菜单导出/导入存档；不要直接清理站点数据。

**NAS 配置够不够？** NAS 主要提供文件，模拟器运行在客户端浏览器。容器默认限制 512 MiB 内存，较大资源库扫描占用会增加。游玩性能还取决于客户端 CPU、GPU 和浏览器。

**能给外网朋友玩吗？** 此家庭版没有登录鉴权，应限于可信局域网。需要外网访问时另行配置 HTTPS、身份验证和访问控制。

**会改变已有续映或游戏厅吗？** 此项目是独立目录和 Compose 服务，默认端口 18888。已有服务占用时更换 `ARCADE_PORT`。不要覆盖旧服务目录。
