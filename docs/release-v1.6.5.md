# v1.6.5：移除旧倒计时流程，暂停期间不重设滤镜

倒计时重写为每秒显示 3、2、1，结束后自动继续。删除原有反复准备画面和滤镜的流程；不添加截图、遮罩、标题或按钮。

暂停菜单原本会在暂停后重新启用滤镜，可能清掉停住的画面。现在保留已经呈现的原画，暂停期间的画面设置推迟到恢复运行后再应用；原画预览和存档缩略图仍可使用。

真实 MAME《恐龙快打》与 FBNeo《拳皇97 最终决战》检查八种滤镜和跨页面读档。新增检查禁止在暂停期间调用原生滤镜切换；MAME 同时使用有界面的 Edge 验证。此前版本仍有实际浏览器黑屏报告，本次验证范围不等于所有设备均已验收。

## 更新部署

Git 安装执行 `git pull --ff-only` 后 `docker compose up -d --build`；ZIP 安装合并 `pixel-arcade-family-v1.6.5.zip` 后重建。账号入口由同一提交生成。保留 ROM、作者滤镜及完整账号数据目录。

缓存标识 `arcade22`、机台样式 `cabinet18`。关闭旧游戏页后重新进入，无需清理网站数据。[更新指南](update.md)。
