# v1.6.2：修正暂停倒计时的半透明背景

移除倒计时中的额外截图画布，直接暂停已经显示的实际游戏画面，叠加 22% 黑色半透明遮罩。避免读取暂停后的 WebGL 缓冲区时得到黑色／不透明截图，将游戏画面盖住。3 秒倒计时、输入屏蔽、失焦暂停和 Esc 取消保持不变。

已检查真实 MAME 游戏倒计时画面，背景清晰可见且核心保持暂停；自动检查覆盖暂停期间不推进、输入屏蔽、半透明遮罩、取消和失焦重置。

## 更新部署

Git 安装执行 `git pull --ff-only` 后 `docker compose up -d --build`；ZIP 安装合并 `pixel-arcade-family-v1.6.2.zip` 后重建。账号入口从同一提交生成前端，无账号后端或数据变更。保留 ROM、作者滤镜及完整账号数据目录。

缓存标识 `arcade19`、机台样式 `cabinet15`。关闭旧游戏页后刷新，无需清理网站数据。[更新指南](update.md)。
