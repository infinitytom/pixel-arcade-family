# v1.4.0：圆角玻璃与账号同步

- 正视机台的游戏画面、玻璃、边框、暂停预览和设置预览统一圆角，配合凹陷压边；关闭机台时恢复完整直角画面。
- 已接入账号服务的入口支持收藏、历史、全局及单游戏画面设置、快捷和自动继续点及缩略图跨设备同步。
- 首次合并当前账号的本机旧记录；离线队列、逐项合并、取消收藏记录、操作重试去重和旧页面账号绑定。状态显示首次迁移、待上传、成功及失败，可手动重试。
- 手动、自动存档各保留 3 份；同毫秒的不同设备进度仍可分别选择。单份云存档上限 16 MB，每账号 512 MB，超限保留本地继续点。

## 更新部署

家庭版 Git 安装执行 `git pull --ff-only`、`docker compose up -d --build`；ZIP 安装合并 `pixel-arcade-family-v1.4.0.zip` 后在原 Compose 项目重新构建。保留 `.env`、ROM、cheats、自定义路径和已导入的 `site/library/private-shaders.json`。公开包不附带作者滤镜资源。

家庭版默认仍无需登录并使用本机数据。已有账号部署还需要安装 `account_sync.py`、在鉴权服务挂载同步路由，并保留持久数据目录；完整接入、备份及同步说明见 [账号同步说明](account-sync.md)。仅替换静态网页不足以启用服务端同步。

保持原入口和账号，关闭旧游戏页后刷新大厅，缓存标识为 `arcade10`。首次登录后等待显示「已同步」，再考虑清除网站数据。校验文件为 `SHA256SUMS-v1.4.0.txt`。[更新部署指南](update.md)。
