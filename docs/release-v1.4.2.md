# v1.4.2：走近机台的入场动画

开始新游戏时，模拟器启动后播放约 0.7 秒的靠近镜头，机台从稍远处向前靠近，街机厅背景以较轻幅度同步推进，最后回到稳定正面。海报在准备期间保留，再淡入实际游戏。

- 确认键、Enter 或点击可跳过，提示图标随输入设备变化；跳过的按键不会同时触发游戏动作。
- 继续存档、关闭机台遮罩或系统开启减少动态效果时直接进入。
- 窗口尺寸变化、页面隐藏或加载失败时取消镜头并恢复正常布局。
- 保留现有滤镜、圆角玻璃、机台结构与账号同步，不改变自动存档周期。

## 更新部署

Git 安装执行 `git pull --ff-only`、`docker compose up -d --build`；ZIP 安装合并 `pixel-arcade-family-v1.4.2.zip` 后重新构建原 Compose 项目。保留 `.env`、ROM、cheats、作者滤镜 JSON 和账号服务的持久数据目录。

账号入口重新生成并部署前端；本版无需更改账号后端或数据库。缓存标识为 `arcade13`。关闭旧游戏页、刷新大厅后选择「开始新游戏」查看动画；继续存档会跳过镜头。无需清除网站数据。校验文件为 `SHA256SUMS-v1.4.2.txt`。详见 [更新部署指南](update.md)。

已验证真实 Web Animations 的时长、输入跳过、减少动态效果、窗口变化与失败清理，以及真实核心的手柄跳过和存档恢复。
