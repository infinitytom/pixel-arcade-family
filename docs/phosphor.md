# 荧光滤镜与本地导入

本版增加荧光线 2.0 的标准、扩散辉光、玻璃反射三个浏览器适配预设，以及荧光点 3.3 的精细 CRT、柔光两个 GLSL 预设。原作者为 **Roc-Y（脑浆油条）**。设置中用中文选择；效果强度、原画对比和单游戏偏好继续可用。

推荐先试「荧光线 2.0 · 标准」的中等强度；希望亮部更柔和可选「扩散辉光」，希望模拟曲面和边缘反光可选「玻璃反射」。较弱的设备可选择标准版、轻强度或原有轻量 CRT。设备、分辨率和浏览器会影响效果与帧率。

## 取得与安装资源

仓库和 Release 不包含作者的原始或转换后的着色器。请自行取得作者资源，保留相关署名与使用条件。工具支持用户提供的 `RetroarchShaders` 总压缩包（包含 PhosphorLine v2.0.zip、PhosphorDot v3.3.zip），也支持单独的荧光点 3.3 ZIP。

在源码项目目录执行：

```sh
python3 scripts/import_phosphor.py /path/to/RetroarchShaders.zip
docker compose up -d --build
```

Windows 可将 `python3` 换成 `py -3`，并为有空格的路径加引号。导入工具只读取 ZIP，生成 `site/library/private-shaders.json`，不会修改原包。这个文件已被 Git 忽略，但正常本地 Docker 构建会将它放进镜像。升级时保留它，避免重新导入。单独安装荧光点包时，未包含的荧光线预设保持不可选。

刷新大厅后打开设置。未导入资源的选项会显示「未导入资源」并禁用。选择高级滤镜后，全局预览会用同款着色器实时渲染本项目自制的像素城市。游戏中也可以在暂停时预览当前画面、调整强度、对比原画，游戏进度不会因此前进。

## 兼容范围

视频中的荧光线 2.0 原包使用 Slang、桌面 GLSL 450 和多段渲染，网页端不能原样加载。导入工具为上述三个指定预设适配 WebGL/GLES 的输入坐标、带填充的纹理尺寸、跨阶段纹理、参数默认值及不支持的数组初始化；保留源计算和署名。这不是通用 Slang 转换器，不包含 ScaleFX、NNEDI3、FSR 等其他组合预设的移植。

荧光点 3.3 使用包内已有 GLSL 版本。运行时仍以模拟器原生着色器链渲染实际游戏；全局与暂停预览使用独立 WebGL 画布，不修改或推进游戏状态。预览采用 8 位帧缓冲，不保证与所有桌面 RetroArch 显卡后端逐像素一致。

导入的文件是站点资源，游戏厅的「清理下载缓存」不删除它。不要为了刷新界面清除浏览器网站数据，收藏和本地存档与核心下载缓存是分开的。
