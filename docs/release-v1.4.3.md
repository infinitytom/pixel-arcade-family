# v1.4.3：大厅控制器选择与接管修补

修复选中大厅控制器后导航无法继续的问题。控制器选项改为直接左右／确认切换，上下离开，避免原生弹出菜单困住焦点。

选择另一台设备时，原手柄会继续工作；新手柄松开按键和摇杆后按确认才正式接管，并消耗这次确认，避免误启动。目标离线会回退自动选择；大厅在此选项按返回可恢复自动并回到游戏列表。游戏玩家分配保持独立。

## 更新部署

Git 安装执行 `git pull --ff-only`、`docker compose up -d --build`；ZIP 安装合并 `pixel-arcade-family-v1.4.3.zip` 后重新构建原 Compose 项目。保留 `.env`、ROM、cheats、作者滤镜 JSON 和账号服务的数据目录。

账号入口重新生成并部署前端；本版无账号后端或数据库变更。缓存标识为 `arcade14`，控制器样式标识为 `gamepad114`。关闭旧游戏页并刷新大厅，无需清除网站数据。校验文件为 `SHA256SUMS-v1.4.3.txt`。详见 [更新部署指南](update.md)。

已覆盖桌面和手机下左右切换、上下离开、返回恢复自动、设置窗口导航、带漂移的设备和两手柄确认接管。
