# 像素放映厅 v1.2.0：机台氛围、进度预览与操作音

本版包含 v1.1.3 之后的完整界面与体验更新。

## 新增与修复

- **街机氛围**：立体木纹／奶白机台、原始／柔和／CRT 滤镜、三档强度和屏幕纹理；全局设置提供即时示例，单个游戏仍可覆盖默认值。
- **历史进度与缩略图**：手动、自动存档各保留最近 3 份。自动保存每 3 分钟一次，手动快捷存档在关闭自动保存时仍可加入列表。大厅、启动页和游戏菜单均可选择时间并查看对应缩略图后恢复。
- **原创操作音**：移动、确认、返回、启动、保存成功和失败使用不同的轻短合成音。默认音量 20%，可试听、调节或关闭；长按移动限频，自动存档成功静音，实际游戏动作不会触发大厅音效。
- **提前适配与动效**：内置 5,720 个 MAME 与 8,461 个 FBNeo 游戏的画面比例记录，启动前布局机台并记住实际比例。海报过渡进入游戏，卡片选中反馈更细腻；支持系统减少动态效果，加载失败可退回重试。
- **手柄与界面**：修复多人分配、稀疏设备编号和插拔恢复、选择框跳项；补充重新识别入口。PS5 创建／选项键使用图形与中文提示，其他设备使用对应图标。
- **金手指与维护**：FBNeo 原生项目及 MAME 原生菜单配中文指引；新增全局默认策略、默认全屏、手动／定期下载缓存清理。缓存维护保留存档、继续点、收藏与配置。

## 下载与已有安装升级

下载本 Release 的 **pixel-arcade-family-v1.2.0.zip**。ZIP 包含程序源码、部署配置与说明，不含 ROM、BIOS、模拟器二进制或金手指数据库；Docker 构建时按锁定文件取得模拟器，金手指数据按需安装。**ui-sounds-preview-v1.2.0.wav** 是六种操作音的短试听，顺序为移动、确认、返回、启动、存档成功、失败。校验文件为 **SHA256SUMS-v1.2.0.txt**。

Git 安装：在原项目目录执行：

```sh
git pull --ff-only
mkdir -p cheats
docker compose up -d --build
docker compose ps
```

ZIP／飞牛安装：备份原项目，把新版程序文件合并到原目录，保留 `.env`、`roms/`、`cheats/` 及自定义游戏目录；在原 Compose 项目重新构建并启动。单独拉取镜像不会更新本地源码构建的部署。

更新后关闭旧游戏页，回到大厅 `Ctrl+F5` 刷新。沿用原协议、域名和端口，**不要清空网站存储**；重要存档建议先导出备份。完整步骤、可选金手指下载命令与回退方法见 [更新部署指南](https://github.com/infinitytom/pixel-arcade-family/blob/v1.2.0/docs/update.md)，功能操作见 [设置与维护](https://github.com/infinitytom/pixel-arcade-family/blob/v1.2.0/docs/settings.md)。

## 验证与兼容说明

本地使用 Edge 和真实 EmulatorJS 4.2.3／MAME、FBNeo 核心检查多人输入、存读档、历史选择、真实缩略图、滤镜与金手指入口；另有实际 Web Audio 录制、静音／限频、横竖屏／宽屏提前布局、动效失败退回及减少动态效果检查。后端 11 项单元测试通过。实体手柄、所有 ROM 的兼容性和具体金手指效果仍需按设备与游戏实测。

旧存档缺少缩略图时显示占位，仍可载入；此前没有保存的画面无法补生成。升级前旧快捷存档可先读取，再重新存档加入历史列表。未知改版首次运行前可能没有画面比例资料，核心实际报告后会记住；也可在 gamelist.xml 中设置 `<aspectratio>3/4</aspectratio>` 等值。浏览器可能要求先点击页面或按键后才能播放操作音。MAME 的原生菜单本体仍为英文，中文对照与退出指引在游戏厅提供。
