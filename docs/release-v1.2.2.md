# v1.2.2：操作音、核心预加载与收藏备份

- 修复只用手柄时音效未初始化的问题。浏览器尚未允许声音时显示启用提示，真实点击或键盘按键后继续用手柄即可；试听仅在音频引擎实际运行后报告成功。默认 20% 音量提升到更容易听清的水平，仍可关闭或调节。
- 游戏详情提前下载默认核心；设置中提供「预加载游戏库所需核心」。启动时通过模拟器支持的文件映射复用二进制，避免调试模式跳过内置缓存导致重复下载。通过服务器 ETag／修改时间检查更新，下载失败回退正常启动流程。
- 核心缓存可随时清理；清理范围仍只包含可重新下载的数据，不删除收藏、最近游玩、游戏存档和继续点。
- 设置显示当前入口、账号及记录数量，新增收藏历史导出、同账号导入、本地上次记录合并恢复。不同入口、浏览器或账号的数据仍互相独立；新功能不能恢复已被浏览器删除且没有备份的数据。游戏存档需单独导出。

## 更新部署

Git 安装在原项目目录运行：

```sh
git pull --ff-only
mkdir -p cheats
docker compose up -d --build
docker compose ps
```

ZIP 安装下载 `pixel-arcade-family-v1.2.2.zip`，保留 `.env`、ROM、cheats 和自定义路径，合并程序文件后重新构建原 Compose 项目。校验文件为 `SHA256SUMS-v1.2.2.txt`。沿用原域名、协议、端口和账号，关闭旧游戏页并刷新大厅。**不要删除网站数据**；缓存标识为 `arcade7`。

详见 [更新部署指南](update.md) 和 [设置维护](settings.md)。包内不含 ROM、BIOS 或模拟器二进制。
