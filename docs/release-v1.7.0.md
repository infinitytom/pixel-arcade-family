# v1.7.0：首页继续游玩

首页顶部展示最近启动的最多 4 款游戏。有存档时展示截图、保存时间和「继续游玩」，直接使用最新存档对应的核心；没有存档时显示封面与「开始游戏」。旧存档没有截图仍可恢复。原宣传区在有历史记录时缩小，没有历史时保留完整首页。

「全部最近游玩」进入完整历史。搜索、分类和收藏等列表隐藏首页区域，手柄 LT／RT 可以切换到该分区，A 确认，Start 继续或开始；由卡片启动后返回大厅恢复卡片焦点。关闭全局继续选项后，卡片仅提供开始新游戏。

账号入口的首页只查询存档摘要和缩略图，不预先下载完整状态；继续游戏时再加载。清单新增会话和预览元数据，兼容现有同步协议，不改变存档格式。公开家庭版继续读取当前浏览器的数据。

## 更新

Git 安装：`git pull --ff-only` 后运行 `docker compose up -d --build`。ZIP 安装：合并 `pixel-arcade-family-v1.7.0.zip` 后重新构建。保留 `.env`、ROM、金手指、作者滤镜、浏览器数据和账号数据卷。账号入口同时更新前端及 `account_sync.py` 后重启服务。

首页缓存标识更新为 `arcade24`。关闭旧游戏页后刷新大厅；无需清理网站数据。

## 验证范围

浏览器回归覆盖本机与账号摘要查询、跨核心最新存档、中文路径、账号隔离、无历史／无存档／无截图、全局继续开关、筛选、桌面和手机布局、生成的手柄输入和返回焦点。后端测试检查预览清单不携带二进制状态且保持账号隔离。实体手柄及新增入口的实际游戏体验仍需使用设备复核。
