# v1.4.1：前伸操作台与机台结构

根据真实街机的正面结构，重新分离直立屏幕、向前伸出的斜面操作台、厚前沿和下方机身。控制台后沿与屏幕下框衔接，前沿加宽；摇杆保持立起，按钮贴合台面。木纹、奶白两种材质及全局设置预览同步更新，屏幕保持正面和圆角，不旋转整个游戏画面。

增加具有真实机台排布、顶灯、座椅和地面反光的街机厅背景；网页资源约 222 KiB。摇杆球头与杆身统一锚点和透视，修复视觉错位。背景生成方式与提示词见 [素材说明](visual-assets.md)。

## 更新部署

Git 安装执行 `git pull --ff-only`、`docker compose up -d --build`；ZIP 安装合并 `pixel-arcade-family-v1.4.1.zip` 后重新构建原 Compose 项目。保留 `.env`、ROM、cheats、作者滤镜 JSON 和账号服务的整个持久数据目录。

已有账号部署重新生成并部署账号前端；本版无数据库迁移或账号后端接口变化。缓存标识为 `arcade12`，关闭旧游戏页并刷新即可，不要清除网站数据。校验文件为 `SHA256SUMS-v1.4.1.txt`。详见 [更新部署指南](update.md)。

已验证桌面、手机竖屏和低高度宽屏下的屏幕对齐、操作台衔接与边界；真实游戏滤镜和设置预览检查通过。
