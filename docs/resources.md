## 完整目录导入

1. 下载后解压外层整合包。不要解压每款街机 ROM 的 ZIP，也不要随意改 ROM 文件名。
2. 找到包含 `gamelist.xml` 的目录，将该目录整体放进项目的 `roms`；也可直接把 `.env` 中的 `ROM_DIR` 指向它。
3. 保留 XML 与各游戏、封面、视频之间的相对路径。
4. 等待约 15 秒，刷新游戏大厅。

没有 `gamelist.xml` 时也可以扫描 ZIP/7z，游戏名使用文件名，封面与简介不会自动下载。文件夹会作为分类。

## ROM 与核心

FBNeo、MAME 和 FBA 使用的 ROM 版本可能不同。大厅可以切换四个核心，但不保证所有 ROM 或 HACK 版本可启动。`kof97.zip` 与 `dino.zip` 默认尝试 MAME 2003 Plus，这是作者原安装的经验，不代表任意同名修改版均可运行。

ROM 文件夹名为 `fbneo`、`mame2003_plus`、`fbalpha2012_cps1`、`fbalpha2012_cps2` 时优先选择对应核心。其余目录按 `DEFAULT_CORE` 配置，默认 FBNeo。

Neo Geo 的 BIOS、PGM 等其他 BIOS 及父 ROM 必须与核心要求相匹配。程序不会下载或生成 BIOS。自己的 `neogeo.zip` 可放在 ROM 同目录或挂载根目录；已有兼容的 `collection-bios.zip` 时可放在挂载根目录供模拟器使用。
